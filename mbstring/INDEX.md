# Multibyte String

Funciones mbstring para manipular cadenas con caracteres multibyte (UTF-8, etc.) de forma segura.

## Orden de lectura

1. **`mb_internal_encoding.php`** - Establecer u obtener la codificación interna de caracteres
2. **`mb_strlen.php`** - Obtener la longitud de una cadena multibyte
3. **`mb_substr.php`** - Extraer una porción de una cadena multibyte
4. **`mb_strpos.php`** - Buscar la posición de una subcadena multibyte
5. **`mb_strtolower.php`** - Convertir una cadena multibyte a minúsculas
6. **`mb_str_split.php`** - Dividir una cadena multibyte en un array de caracteres
7. **`mb_detect_encoding.php`** - Detectar la codificación de una cadena
8. **`mb_convert_encoding.php`** - Convertir una cadena de una codificación a otra
