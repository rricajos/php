# Fecha y hora

Funciones para obtener, formatear, crear y manipular fechas y horas en PHP.

## Orden de lectura

1. **`time.php`** - Obtener la marca de tiempo Unix actual
2. **`date.php`** - Formatear una marca de tiempo como cadena legible
3. **`mktime.php`** - Crear una marca de tiempo a partir de componentes de fecha
4. **`strtotime.php`** - Convertir una descripción textual de fecha a marca de tiempo
5. **`checkdate.php`** - Validar si una fecha es correcta
6. **`microtime.php`** - Obtener la marca de tiempo con precisión de microsegundos
7. **`date_create.php`** - Crear un objeto DateTime
8. **`date_format.php`** - Formatear un objeto DateTime como cadena
9. **`date_diff.php`** - Calcular la diferencia entre dos fechas
10. **`date_interval_create_from_date_string.php`** - Crear un intervalo a partir de una cadena descriptiva
