# cURL

Funciones de la extensión cURL para realizar peticiones HTTP desde PHP.

## Orden de lectura

1. **`curl_init.php`** - Inicializar una sesión cURL
2. **`curl_setopt.php`** - Configurar opciones de una sesión cURL
3. **`curl_post.php`** - Realizar una petición POST con cURL
4. **`curl_getinfo.php`** - Obtener información sobre una transferencia realizada
5. **`curl_error.php`** - Obtener el último mensaje de error de cURL
6. **`curl_multi.php`** - Ejecutar múltiples peticiones cURL en paralelo
