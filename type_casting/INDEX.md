# Type Casting

Conversion de tipos y declaraciones de tipo para un codigo PHP mas seguro y predecible.

## Orden de lectura

1. **`casting.php`** - Casting explicito con (int), (float), (string), (bool), type juggling y funciones de conversion
2. **`type_declarations.php`** - Declaraciones de tipo: strict_types, tipos escalares, union, intersection, nullable y never
