# ArrayObject

Clase que permite trabajar con arrays como si fueran objetos, con acceso mediante propiedades y métodos.

## Orden de lectura

1. **`24_methods/ArrayObject_construct.php`** - Crear una instancia de ArrayObject
2. **`2_properties/ArrayObject_STD_PROP_LIST.php`** - Constante para listar propiedades del objeto
3. **`2_properties/ArrayObject_ARRAY_AS_PROPS.php`** - Constante para acceder a elementos como propiedades
4. **`24_methods/ArrayObject_getFlags.php`** - Obtener las banderas de comportamiento actuales
5. **`24_methods/ArrayObject_setFlags.php`** - Establecer las banderas de comportamiento
6. **`24_methods/ArrayObject_offsetExists.php`** - Verificar si un índice existe
7. **`24_methods/ArrayObject_offsetGet.php`** - Obtener el valor de un índice
8. **`24_methods/ArrayObject_offsetSet.php`** - Asignar un valor a un índice
9. **`24_methods/ArrayObject_offsetUnset.php`** - Eliminar un índice
10. **`24_methods/ArrayObject_append.php`** - Agregar un valor al final
11. **`24_methods/ArrayObject_count.php`** - Contar el número de elementos
12. **`24_methods/ArrayObject_getArrayCopy.php`** - Obtener una copia del array interno
13. **`24_methods/ArrayObject_exchangeArray.php`** - Reemplazar el array interno por otro
14. **`24_methods/ArrayObject_getIterator.php`** - Obtener un iterador externo
15. **`24_methods/ArrayObject_getIteratorClass.php`** - Obtener la clase del iterador
16. **`24_methods/ArrayObject_setIteratorClass.php`** - Establecer la clase del iterador
17. **`24_methods/ArrayObject_asort.php`** - Ordenar por valores manteniendo claves
18. **`24_methods/ArrayObject_ksort.php`** - Ordenar por claves
19. **`24_methods/ArrayObject_natsort.php`** - Ordenar con algoritmo de orden natural
20. **`24_methods/ArrayObject_natcasesort.php`** - Orden natural sin distinguir mayúsculas
21. **`24_methods/ArrayObject_uasort.php`** - Ordenar con función de comparación personalizada
22. **`24_methods/ArrayObject_uksort.php`** - Ordenar por claves con función personalizada
23. **`24_methods/ArrayObject_serialize.php`** - Serializar el ArrayObject
24. **`24_methods/ArrayObject_unserialize.php`** - Deserializar un ArrayObject
