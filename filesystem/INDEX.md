# Sistema de archivos

Funciones para verificar, leer, escribir, organizar y gestionar archivos y directorios en PHP.

## Orden de lectura

1. **`file_exists.php`** - Comprobar si un archivo o directorio existe
2. **`is_file.php`** - Verificar si una ruta corresponde a un archivo
3. **`is_dir.php`** - Verificar si una ruta corresponde a un directorio
4. **`basename.php`** - Obtener el nombre del archivo de una ruta
5. **`dirname.php`** - Obtener el directorio padre de una ruta
6. **`realpath.php`** - Obtener la ruta absoluta canónica
7. **`pathinfo.php`** - Obtener información desglosada de una ruta
8. **`file_get_contents.php`** - Leer el contenido completo de un archivo
9. **`fopen.php`** - Abrir un archivo con control detallado de lectura y escritura
10. **`file_put_contents.php`** - Escribir contenido en un archivo
11. **`mkdir.php`** - Crear un directorio
12. **`scandir.php`** - Listar archivos y directorios de una ruta
13. **`glob.php`** - Buscar rutas que coincidan con un patrón
14. **`copy.php`** - Copiar un archivo
15. **`rename.php`** - Renombrar o mover un archivo o directorio
16. **`unlink.php`** - Eliminar un archivo
