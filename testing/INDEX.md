# Testing

Pruebas unitarias con PHPUnit: aserciones, datos de prueba, dobles y metodologia TDD.

## Orden de lectura

1. **`phpunit_basics.php`** - Fundamentos de PHPUnit: estructura de tests, ejecucion desde CLI y mini-framework independiente
2. **`assertions.php`** - Catalogo de aserciones: assertEquals, assertTrue, assertSame, assertContains y mas de 20 metodos
3. **`data_providers.php`** - Data Providers: pruebas parametrizadas con multiples conjuntos de datos reutilizables
4. **`mocks_stubs.php`** - Mocks, stubs y dobles de prueba: aislar dependencias con fake, spy y mock objects
5. **`test_organization.php`** - Organizacion de pruebas: setUp/tearDown, dependencias, grupos y estructura de directorios
6. **`tdd_example.php`** - TDD paso a paso: ciclo rojo-verde-refactorizar con ejemplos de Calculator y ShoppingCart
