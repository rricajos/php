# Expresiones regulares

Funciones PCRE de PHP para buscar, reemplazar y dividir cadenas mediante patrones de expresiones regulares.

## Orden de lectura

1. **`preg_match.php`** - Buscar la primera coincidencia de un patrón en una cadena
2. **`preg_match_all.php`** - Buscar todas las coincidencias de un patrón en una cadena
3. **`preg_replace.php`** - Reemplazar coincidencias de un patrón con una cadena
4. **`preg_replace_callback.php`** - Reemplazar coincidencias usando una función callback
5. **`preg_split.php`** - Dividir una cadena usando un patrón como delimitador
6. **`preg_quote.php`** - Escapar caracteres especiales de expresiones regulares
