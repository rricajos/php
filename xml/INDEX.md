# XML

Procesamiento de documentos XML y HTML con las distintas APIs de PHP.

## Orden de lectura

1. **`simplexml.php`** - SimpleXML: carga, acceso a elementos y atributos, iteracion, XPath y parseador de RSS
2. **`dom_document.php`** - DOMDocument: crear XML desde cero, CDATA, loadHTML, DOMXPath y plantilla de email HTML
3. **`xpath.php`** - XPath avanzado: predicados, funciones, namespaces, ejes de navegacion y scraping de tablas HTML
4. **`xmlreader_xmlwriter.php`** - XMLReader y XMLWriter: procesamiento en streaming para archivos grandes y transformaciones
