# Math

Funciones matemáticas de PHP para operaciones aritméticas, redondeo, comparación, aleatoriedad y conversión numérica.

## Orden de lectura

1. **`abs.php`** - Obtener el valor absoluto de un número
2. **`ceil.php`** - Redondear un número hacia arriba
3. **`floor.php`** - Redondear un número hacia abajo
4. **`round.php`** - Redondear un número con precisión configurable
5. **`max.php`** - Obtener el valor máximo de un conjunto de valores
6. **`min.php`** - Obtener el valor mínimo de un conjunto de valores
7. **`pow.php`** - Calcular la potencia de un número
8. **`sqrt.php`** - Calcular la raíz cuadrada de un número
9. **`fmod.php`** - Obtener el residuo de una división con punto flotante
10. **`intdiv.php`** - Realizar una división entera
11. **`pi.php`** - Obtener el valor de la constante Pi
12. **`log.php`** - Calcular el logaritmo de un número
13. **`rand.php`** - Generar un número entero aleatorio
14. **`mt_rand.php`** - Generar un aleatorio con el algoritmo Mersenne Twister
15. **`random_int.php`** - Generar un entero aleatorio criptográficamente seguro
16. **`base_convert.php`** - Convertir un número entre bases numéricas
