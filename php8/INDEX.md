# PHP 8.x

Funcionalidades introducidas en PHP 8.0, 8.1 y 8.2 que modernizan el lenguaje.

## Orden de lectura

1. **`match.php`** - Expresion match como alternativa a switch con comparacion estricta y retorno de valor
2. **`named_arguments.php`** - Argumentos nombrados para saltar valores por defecto y mejorar legibilidad
3. **`constructor_promotion.php`** - Promocion de parametros del constructor para reducir codigo repetitivo
4. **`union_types.php`** - Tipos union para aceptar multiples tipos en parametros, retornos y propiedades
5. **`nullsafe_operator.php`** - Operador ?-> para encadenar accesos seguros cuando hay valores null
6. **`readonly.php`** - Propiedades y clases readonly para crear objetos inmutables
7. **`enums.php`** - Enumeraciones con valores respaldados, metodos e implementacion de interfaces
8. **`intersection_types.php`** - Tipos de interseccion para exigir multiples interfaces simultaneamente
9. **`attributes.php`** - Atributos nativos para anadir metadatos estructurados a clases y metodos
10. **`first_class_callables.php`** - Sintaxis Closure::fromCallable abreviada con func(...) para crear closures
11. **`fibers.php`** - Fibers para ejecucion cooperativa con suspension y reanudacion manual
