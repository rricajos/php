# Programación orientada a objetos

Conceptos fundamentales de la programación orientada a objetos en PHP.

## Orden de lectura

1. **`classes.php`** - Definir clases y crear objetos
2. **`constructor.php`** - Inicializar objetos con el método constructor
3. **`visibility.php`** - Controlar el acceso con public, protected y private
4. **`constants.php`** - Definir constantes de clase
5. **`inheritance.php`** - Extender clases mediante herencia
6. **`abstract.php`** - Crear clases y métodos abstractos
7. **`interfaces.php`** - Definir contratos con interfaces
8. **`traits.php`** - Reutilizar código con traits
9. **`static.php`** - Usar propiedades y métodos estáticos
10. **`magic_methods.php`** - Implementar métodos mágicos (__get, __set, __toString, etc.)
