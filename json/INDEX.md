# JSON

Funciones para codificar y decodificar datos en formato JSON en PHP.

## Orden de lectura

1. **`json_encode.php`** - Convertir un valor de PHP a su representación JSON
2. **`json_decode.php`** - Decodificar una cadena JSON a un valor de PHP
3. **`json_last_error.php`** - Obtener el último error ocurrido en una operación JSON
