# Output Buffering

Control del buffer de salida de PHP para capturar, manipular y gestionar la salida generada.

## Orden de lectura

1. **`ob_start.php`** - Funciones basicas del buffer: ob_start, ob_get_contents, buffers anidados y callbacks
2. **`ob_practical.php`** - Usos practicos: capturar HTML, sistema de plantillas, prevencion de errores de headers y cache
