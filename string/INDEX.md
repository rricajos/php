# Strings

Funciones nativas de PHP para inspeccionar, transformar, buscar, reemplazar, formatear y codificar cadenas de texto.

## Orden de lectura

1. **`strlen.php`** - Obtener la longitud de una cadena
2. **`strtolower.php`** - Convertir una cadena a minúsculas
3. **`strtoupper.php`** - Convertir una cadena a mayúsculas
4. **`lcfirst.php`** - Convertir el primer carácter a minúscula
5. **`ucfirst.php`** - Convertir el primer carácter a mayúscula
6. **`ucwords.php`** - Convertir la primera letra de cada palabra a mayúscula
7. **`trim.php`** - Eliminar espacios en blanco al inicio y final
8. **`ltrim.php`** - Eliminar espacios en blanco al inicio
9. **`rtrim.php`** - Eliminar espacios en blanco al final
10. **`substr.php`** - Extraer una porción de una cadena
11. **`substr_count.php`** - Contar las apariciones de una subcadena
12. **`substr_replace.php`** - Reemplazar una porción de una cadena
13. **`strpos.php`** - Buscar la primera posición de una subcadena
14. **`stripos.php`** - Buscar la primera posición sin distinguir mayúsculas
15. **`strrpos.php`** - Buscar la última posición de una subcadena
16. **`strripos.php`** - Buscar la última posición sin distinguir mayúsculas
17. **`str_contains.php`** - Verificar si una cadena contiene otra
18. **`str_starts_with.php`** - Verificar si una cadena comienza con otra
19. **`str_ends_with.php`** - Verificar si una cadena termina con otra
20. **`str_replace.php`** - Reemplazar todas las ocurrencias de una subcadena
21. **`str_ireplace.php`** - Reemplazar sin distinguir mayúsculas
22. **`explode.php`** - Dividir una cadena en un array usando un delimitador
23. **`implode.php`** - Unir elementos de un array en una cadena
24. **`str_split.php`** - Dividir una cadena en un array de fragmentos
25. **`sprintf.php`** - Formatear una cadena con marcadores de posición
26. **`printf.php`** - Imprimir una cadena formateada directamente
27. **`number_format.php`** - Formatear un número con separadores de miles y decimales
28. **`str_pad.php`** - Rellenar una cadena hasta una longitud determinada
29. **`str_repeat.php`** - Repetir una cadena un número de veces
30. **`strrev.php`** - Invertir una cadena
31. **`str_word_count.php`** - Contar el número de palabras en una cadena
32. **`wordwrap.php`** - Ajustar una cadena a un número de caracteres por línea
33. **`chunk_split.php`** - Dividir una cadena en fragmentos con un separador
34. **`nl2br.php`** - Convertir saltos de línea en etiquetas HTML `<br>`
35. **`htmlspecialchars.php`** - Convertir caracteres especiales a entidades HTML
36. **`htmlentities.php`** - Convertir todos los caracteres aplicables a entidades HTML
37. **`strip_tags.php`** - Eliminar etiquetas HTML y PHP de una cadena
38. **`addslashes.php`** - Escapar caracteres especiales con barras invertidas
39. **`stripslashes.php`** - Eliminar barras invertidas de escape
40. **`strcmp.php`** - Comparar dos cadenas (sensible a mayúsculas)
41. **`strcasecmp.php`** - Comparar dos cadenas sin distinguir mayúsculas
42. **`strncmp.php`** - Comparar los primeros n caracteres de dos cadenas
43. **`chr.php`** - Obtener un carácter a partir de su código ASCII
44. **`ord.php`** - Obtener el código ASCII de un carácter
45. **`md5.php`** - Generar el hash MD5 de una cadena
46. **`sha1.php`** - Generar el hash SHA-1 de una cadena
47. **`base64_encode.php`** - Codificar datos en formato Base64
48. **`base64_decode.php`** - Decodificar datos desde formato Base64
49. **`str_getcsv.php`** - Parsear una cadena CSV en un array
