# Manejo de errores

Tecnicas para gestionar errores y excepciones en PHP de forma robusta.

## Orden de lectura

1. **`error_reporting.php`** - Niveles de reporte de errores, display_errors y configuracion por entorno
2. **`try_catch.php`** - Bloques try/catch, multiples catch, union de tipos y validacion con excepciones
3. **`finally.php`** - Bloque finally: comportamiento con return, limpieza de recursos y transacciones
4. **`custom_exceptions.php`** - Excepciones personalizadas: jerarquias, contexto, encadenamiento y HTTP tipadas
5. **`set_error_handler.php`** - Manejador personalizado de errores, conversion a excepciones y logger
6. **`set_exception_handler.php`** - Manejador global de excepciones no capturadas, formato JSON/HTML y logging
