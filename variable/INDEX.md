# Variables

Funciones para verificar tipos, comprobar existencia, convertir valores y depurar variables en PHP.

## Orden de lectura

1. **`gettype.php`** - Obtener el tipo de una variable como cadena
2. **`is_string.php`** - Verificar si una variable es de tipo string
3. **`is_int.php`** - Verificar si una variable es de tipo entero
4. **`is_float.php`** - Verificar si una variable es de tipo flotante
5. **`is_bool.php`** - Verificar si una variable es de tipo booleano
6. **`is_null.php`** - Verificar si una variable es null
7. **`is_numeric.php`** - Verificar si una variable es numérica o una cadena numérica
8. **`is_array.php`** - Verificar si una variable es un array
9. **`is_object.php`** - Verificar si una variable es un objeto
10. **`isset.php`** - Comprobar si una variable existe y no es null
11. **`empty.php`** - Comprobar si una variable está vacía
12. **`settype.php`** - Cambiar el tipo de una variable
13. **`intval.php`** - Convertir una variable a entero
14. **`floatval.php`** - Convertir una variable a flotante
15. **`strval.php`** - Convertir una variable a cadena
16. **`boolval.php`** - Convertir una variable a booleano
17. **`var_dump.php`** - Mostrar tipo y valor de una variable con detalle
18. **`print_r.php`** - Mostrar información legible de una variable
19. **`var_export.php`** - Exportar una variable como código PHP válido
